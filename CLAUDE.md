# CLAUDE.md

Classic Fizz Pose Workshop is Liminal HQ's Bun/Vite/TypeScript art lab for Ben Blaze: a pixel editor, sprite animation rigs and a volumetric Three.js character study. Read [AGENTS.md](AGENTS.md) for the authoritative contributor rules and [README.md](README.md) for setup and artwork context.

Use Canadian English, focused signed Conventional Commits and the Liminal HQ source header. Do not push or change shared settings without explicit instruction. Preserve original art, saved editor overrides and reusable rigs. Edit `templates/README.md` rather than its generated root copy. `bun run generate` exports saved artwork; `draw:*` redraws it and can replace manual changes.

Run `bun run validate` for application changes and inspect visual changes in the browser. Use `bun run branding:build` to refresh the animated SVG hero and matching SVG/PNG repository avatars after deliberate changes to their saved sprite references. Consult `docs/RIG.md`, `docs/BEN_3D.md` and `docs/TURNTABLE_REVIEW.md` before changing motion, model proportions or rotating views.
